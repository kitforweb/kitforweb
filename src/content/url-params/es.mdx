## ¿Qué hace?

Desglosa una URL —por larga que sea— en una **tabla de parámetros decodificados**. Los enlaces de seguimiento, las redirecciones de OAuth y las URLs de búsqueda se vuelven legibles en un segundo:

- `%C3%A9` y `+` se decodifican, así que `caf%C3%A9+con+leche` se lee `café con leche`.
- Las claves repetidas aparecen una a una.
- Los parámetros del **fragmento** (`#access_token=…`) tienen su propia sección.
- Los valores que son **JSON**, **JWT**, **Base64** o **URLs anidadas** (`redirect_uri`) se reconocen y se decodifican debajo del valor.

## Cómo se usa

1. Pega una URL. El esquema es opcional: `example.com/?a=1` también funciona.
2. Usa el buscador para encontrar un parámetro entre decenas.
3. Edita cualquier valor: la **URL reconstruida** aparece abajo, correctamente codificada.

## Anatomía de una URL

```
https://tienda.example.com/buscar?q=cafe&page=2#opiniones
└─┬─┘   └───────┬────────┘└──┬──┘└─────┬────┘└───┬────┘
esquema        host         ruta     query    fragmento
```
