## What does it do?

It converts **JSON to YAML** and **YAML to JSON**. YAML is the format of GitHub Actions, GitLab CI, docker-compose, Kubernetes, Ansible and many OpenAPI specs, while JSON is what your code and APIs speak.

## How to use it

1. Paste JSON on the left: the YAML version appears on the right.
2. Press **Swap** to switch to YAML → JSON (the current result moves to the input).
3. Choose 2 or 4 spaces of indentation.

## Example

```yaml
on:
  push:
    branches: [main]
```

is the same as

```json
{ "on": { "push": { "branches": ["main"] } } }
```

## Common YAML pitfalls

- **Tabs** are not allowed for indentation: use spaces.
- `on`, `yes` or `no` may be read as booleans by old YAML 1.1 parsers; quote them if in doubt.
- Strings with `:` followed by a space, or starting with `*`, `&` or `!`, need quotes.
