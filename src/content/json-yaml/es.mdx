## ¿Qué hace?

Convierte **JSON a YAML** y **YAML a JSON**. YAML es el formato de GitHub Actions, GitLab CI, docker-compose, Kubernetes, Ansible y muchas especificaciones OpenAPI, mientras que JSON es el que hablan tu código y tus APIs.

## Cómo se usa

1. Pega JSON a la izquierda: la versión YAML aparece a la derecha.
2. Pulsa **Intercambiar** para pasar a YAML → JSON (el resultado actual pasa a la entrada).
3. Elige 2 o 4 espacios de sangría.

## Ejemplo

```yaml
on:
  push:
    branches: [main]
```

equivale a

```json
{ "on": { "push": { "branches": ["main"] } } }
```

## Trampas habituales de YAML

- No se pueden usar **tabuladores** para indentar: usa espacios.
- `on`, `yes` o `no` pueden leerse como booleanos en analizadores antiguos de YAML 1.1; ponlos entre comillas si tienes dudas.
- Los textos con `:` seguido de espacio, o que empiezan por `*`, `&` o `!`, necesitan comillas.
