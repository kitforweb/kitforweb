## What does it do?

It optimizes SVG files with **SVGO**, the same engine used by most build tools. Design apps export a lot of things browsers do not need: editor metadata, comments, empty groups, default attributes, coordinates with six decimals. Removing them often makes the file **50–80% smaller**.

## Options

- **Precision**: decimals kept in coordinates.
- **Multipass**: repeats the optimization until nothing else can be removed.
- **Indent**: readable output instead of a single line.
- **viewBox** and **title**: kept by default, since they matter for resizing and accessibility.

## Typical savings

An icon exported from Inkscape with metadata and nested groups can go from about 2 KB to 300 bytes, which adds up when a page inlines dozens of icons.
