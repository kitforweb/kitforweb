## ¿Qué hace?

Responde a la pregunta **«¿esta versión cumple este rango?»** con las mismas reglas que npm, y explica el rango con comparadores simples: `^1.2.3` pasa a ser `>=1.2.3 <2.0.0-0`. También te da la versión mínima que cumple el rango y **ordena listas de versiones semánticamente**, para que `1.10.0` vaya después de `1.9.0` y no después de `1.1.0`.

## El versionado semántico en una línea

`MAYOR.MENOR.PARCHE`: sube la **mayor** para cambios incompatibles, la **menor** para funciones nuevas compatibles y el **parche** para correcciones. Las prerelease añaden un sufijo: `2.0.0-rc.1`.

## Rangos que verás en package.json

| Rango | Acepta |
| --- | --- |
| `^1.2.3` | `>=1.2.3 <2.0.0` |
| `~1.2.3` | `>=1.2.3 <1.3.0` |
| `1.x` | `>=1.0.0 <2.0.0` |
| `>=18 <21` | Node 18, 19 y 20 |
| `^16 \|\| ^18` | cualquiera de las dos mayores |
