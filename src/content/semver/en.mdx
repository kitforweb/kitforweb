## What does it do?

It answers the question **“does this version satisfy this range?”** using the same rules as npm, and explains the range in plain comparators: `^1.2.3` becomes `>=1.2.3 <2.0.0-0`. It also gives the lowest version that satisfies the range, and **sorts lists of versions semantically**, so `1.10.0` comes after `1.9.0` and not after `1.1.0`.

## Semantic versioning in one line

`MAJOR.MINOR.PATCH`: increase **major** for breaking changes, **minor** for new compatible features and **patch** for fixes. Prereleases add a suffix: `2.0.0-rc.1`.

## Ranges you will see in package.json

| Range | Accepts |
| --- | --- |
| `^1.2.3` | `>=1.2.3 <2.0.0` |
| `~1.2.3` | `>=1.2.3 <1.3.0` |
| `1.x` | `>=1.0.0 <2.0.0` |
| `>=18 <21` | Node 18, 19 and 20 |
