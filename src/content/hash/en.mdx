## What does it do?

It calculates the **MD5, SHA-1, SHA-256, SHA-384 and SHA-512** hashes of a text or a file at the same time, in hexadecimal or Base64. SHA hashes use the browser's Web Crypto API; MD5, which Web Crypto does not include, uses spark-md5. Files are read locally, so you can hash gigabyte ISO images without uploading anything.

## How to use it

1. Type or paste text, or press **Hash a file**.
2. Switch the output between **Hex** and **Base64**. In Base64 mode you also get the **SRI** value for `integrity` attributes.
3. Paste a published checksum in **Expected hash** to verify it.

## Subresource Integrity

```html
<script src="https://cdn.example.com/lib.js"
        integrity="sha384-…"
        crossorigin="anonymous"></script>
```

The browser refuses to run the file if its SHA-384 does not match, protecting you from a compromised CDN.
