## ¿Qué hace?

Calcula a la vez los hashes **MD5, SHA-1, SHA-256, SHA-384 y SHA-512** de un texto o un archivo, en hexadecimal o Base64. Los SHA usan la API Web Crypto del navegador; MD5, que Web Crypto no incluye, usa spark-md5. Los archivos se leen en local, así que puedes calcular el hash de una ISO de varios gigas sin subir nada.

## Cómo se usa

1. Escribe o pega un texto, o pulsa **Calcular de un archivo**.
2. Cambia la salida entre **Hex** y **Base64**. En Base64 también obtienes el valor **SRI** para atributos `integrity`.
3. Pega un checksum publicado en **Hash esperado** para verificarlo.

## Vectores de prueba

| Entrada | SHA-256 |
| --- | --- |
| (vacío) | `e3b0c442…7852b855` |
| `abc` | `ba7816bf…f20015ad` |

## Subresource Integrity

```html
<script src="https://cdn.example.com/lib.js"
        integrity="sha384-…"
        crossorigin="anonymous"></script>
```

El navegador se niega a ejecutar el archivo si su SHA-384 no coincide, lo que te protege de un CDN comprometido.
