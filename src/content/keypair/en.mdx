## What does it do?

It has two modes:

- **Generate** an **RSA** (2048, 3072 or 4096 bits), **elliptic curve** (P-256, P-384, P-521) or **Ed25519** key pair and export it as **PEM** (PKCS#8 private key, SPKI public key) and **JWK**.
- **Convert** an existing key from PEM to JWK or from JWK to PEM. Public and private keys are both supported.

## Generating the same keys with OpenSSL

```bash
openssl genpkey -algorithm EC -pkeyopt ec_paramgen_curve:P-256 -out private.pem
openssl pkey -in private.pem -pubout -out public.pem
```

## PEM headers

| Header | Contents |
| --- | --- |
| `BEGIN PUBLIC KEY` | public key, SPKI |
| `BEGIN PRIVATE KEY` | private key, PKCS#8 |
| `BEGIN RSA PRIVATE KEY` | legacy PKCS#1 RSA key: convert it with `openssl pkcs8 -topk8 -nocrypt` |
