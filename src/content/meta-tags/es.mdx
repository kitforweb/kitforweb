## ¿Qué hace?

Rellenas el **título**, la **descripción**, la **URL** y la **imagen** de una página y ves, en vivo, cómo quedará en:

- Los resultados de **Google**.
- Las tarjetas de enlace de **LinkedIn** y Facebook.
- Las tarjetas de **X (Twitter)**.
- Las vistas previas de enlaces de **WhatsApp**.

Los contadores de caracteres te avisan si el título o la descripción se quedan cortos o se van a cortar. Debajo de las vistas previas tienes las etiquetas listas para pegar en el `head` de tu página: `title`, `description`, `canonical`, **Open Graph** y **Twitter Card**.

## En Next.js

```ts
export const metadata = {
  title: "Mi página",
  description: "De qué trata la página.",
  openGraph: { images: ["https://example.com/og.png"] },
};
```

Next.js genera las mismas etiquetas a partir del objeto `metadata` de cada página.
