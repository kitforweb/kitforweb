## What does it do?

You fill in the **title**, **description**, **URL** and **image** of a page and see, live, how it will look in:

- **Google** search results.
- **LinkedIn** and Facebook link cards.
- **X (Twitter)** cards.
- **WhatsApp** link previews.

The character counters warn you when the title or the description is too short or will be cut. Below the previews you get the tags ready to paste in the `head` of your page: `title`, `description`, `canonical`, **Open Graph** and **Twitter Card**.

## In Next.js

```ts
export const metadata = {
  title: "My page",
  description: "What the page is about.",
  openGraph: { images: ["https://example.com/og.png"] },
};
```

Next.js generates the same tags from the `metadata` object of each page.
