## What does it do?

It computes the **HMAC** (hash-based message authentication code) of a message with a secret key, using SHA-256, SHA-384, SHA-512 or SHA-1, and shows it in hex and Base64. Paste the signature you received and the tool tells you whether it matches.

## How to use it

1. Paste the **raw body** of the request, byte for byte.
2. Type the **secret key**. If your provider gives it in hex or Base64, change the key format.
3. Paste the signature header you received (`sha256=…`, `t=…,v1=…`, hex or Base64) to check it.

## Verifying a GitHub webhook in Node.js

```js
import { createHmac, timingSafeEqual } from "node:crypto";

const expected = "sha256=" + createHmac("sha256", secret).update(rawBody).digest("hex");
const valid = timingSafeEqual(Buffer.from(expected), Buffer.from(req.headers["x-hub-signature-256"]));
```
