## ¿Qué hace?

Calcula el **HMAC** (código de autenticación de mensajes basado en hash) de un mensaje con una clave secreta, usando SHA-256, SHA-384, SHA-512 o SHA-1, y lo muestra en hex y Base64. Pega la firma que recibiste y la herramienta te dice si coincide.

## Cómo se usa

1. Pega el **cuerpo sin procesar** de la petición, byte a byte.
2. Escribe la **clave secreta**. Si tu proveedor te la da en hex o Base64, cambia el formato de la clave.
3. Pega la cabecera de firma que recibiste (`sha256=…`, `t=…,v1=…`, hex o Base64) para comprobarla.

## Verificar un webhook de GitHub en Node.js

```js
import { createHmac, timingSafeEqual } from "node:crypto";

const expected = "sha256=" + createHmac("sha256", secret).update(rawBody).digest("hex");
const valid = timingSafeEqual(Buffer.from(expected), Buffer.from(req.headers["x-hub-signature-256"]));
```
