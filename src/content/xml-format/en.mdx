## What does it do?

It **formats XML** with consistent indentation, **minifies it** to a single line and **validates that it is well formed**. When the document is broken, the error says **what is wrong and on which line and column**: a tag that is not closed, an attribute without quotes, a stray `&`.

## Typical uses

- Reading a SOAP request or response copied from a log.
- Checking an SVG, RSS feed, sitemap or Maven `pom.xml` before deploying it.
- Compacting XML to embed it in a string or a test fixture.

## Example

`<order><id>42</id><items><item sku="A1"/></items></order>` becomes

```xml
<order>
  <id>42</id>
  <items>
    <item sku="A1"/>
  </items>
</order>
```
