## What does it do?

It generates the **bcrypt** hash of a password with the cost factor you choose, and checks whether a password **matches** an existing bcrypt hash — for example, one copied from your users table while debugging a login.

bcrypt runs in your browser with bcryptjs. Passwords are not stored, not put in the URL and never sent anywhere.

## Anatomy of a bcrypt hash

```
$2b$10$WDHsS2e05u6fibtdF4fGpOLaoZCbgsENgQwk5ytDhrADLa89sOyYa
 │   │  └──────── salt (22) ───────┘└──────── hash (31) ────────┘
 │   └ cost: 2^10 = 1024 rounds
 └ version
```

## Limits

bcrypt only uses the **first 72 bytes** of a password. Longer passphrases, or text with many multi-byte characters, are silently truncated; the tool warns you when that happens.
