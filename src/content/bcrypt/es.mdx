## ¿Qué hace?

Genera el hash **bcrypt** de una contraseña con el factor de coste que elijas, y comprueba si una contraseña **coincide** con un hash bcrypt existente —por ejemplo, uno copiado de tu tabla de usuarios mientras depuras un login.

bcrypt se ejecuta en tu navegador con bcryptjs. Las contraseñas no se guardan, no van en la URL y nunca se envían a ningún sitio.

## Anatomía de un hash bcrypt

```
$2b$10$WDHsS2e05u6fibtdF4fGpOLaoZCbgsENgQwk5ytDhrADLa89sOyYa
 │   │  └──────── sal (22) ────────┘└──────── hash (31) ────────┘
 │   └ coste: 2^10 = 1024 rondas
 └ versión
```

## Límites

bcrypt solo usa los **primeros 72 bytes** de la contraseña. Las frases más largas, o los textos con muchos caracteres multibyte, se truncan sin avisar; la herramienta te avisa cuando ocurre.
