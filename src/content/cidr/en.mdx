## What does it do?

It describes a **CIDR block**: netmask, wildcard, network and broadcast addresses, the range of usable hosts and how many there are. It also tells you whether an address is **private, public, loopback or CGNAT**, checks whether an IP **belongs to the block** and **splits the block into smaller subnets**.

## How to use it

- Type a block such as `10.0.0.0/16`, an IP with its mask (`10.0.0.1 255.255.0.0`) or a single IP.
- Type an IP in the second field to check if it is inside the range: useful for firewall rules, security groups and allowlists.
- Choose a prefix in **Split into** to plan subnets, for example a `/16` VPC split into `/24` subnets.
