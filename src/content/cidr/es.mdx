## ¿Qué hace?

Describe un **bloque CIDR**: máscara, wildcard, direcciones de red y broadcast, el rango de hosts utilizables y cuántos son. También te dice si una dirección es **privada, pública, loopback o CGNAT**, comprueba si una IP **pertenece al bloque** y **divide el bloque en subredes más pequeñas**.

## Cómo se usa

- Escribe un bloque como `10.0.0.0/16`, una IP con su máscara (`10.0.0.1 255.255.0.0`) o una IP suelta.
- Escribe una IP en el segundo campo para comprobar si está dentro del rango: útil para reglas de firewall, security groups y listas de IPs permitidas.
- Elige un prefijo en **Dividir en** para planificar subredes, por ejemplo una VPC `/16` dividida en subredes `/24`.
