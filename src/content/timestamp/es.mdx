## ¿Qué hace?

Convierte entre el **tiempo Unix** (epoch) y fechas legibles:

- **Epoch → fecha**: segundos, milisegundos, microsegundos o nanosegundos, detectados por su longitud.
- **Fecha → epoch**: ISO 8601, RFC 2822 o una fecha elegida en el calendario.
- Todas las representaciones a la vez: ISO 8601, UTC, tu hora local con su zona horaria, un tiempo relativo («hace 3 horas»), el día de la semana, la semana ISO y el día del año.

Arriba se muestra el timestamp actual en vivo, listo para copiar.

## Obtener el timestamp actual

| Lenguaje | Segundos | Milisegundos |
| --- | --- | --- |
| JavaScript | `Math.floor(Date.now() / 1000)` | `Date.now()` |
| Python | `int(time.time())` | `int(time.time() * 1000)` |
| PHP | `time()` | `(int) (microtime(true) * 1000)` |
| Bash | `date +%s` | `date +%s%3N` |
| SQL (PostgreSQL) | `extract(epoch from now())` | |
