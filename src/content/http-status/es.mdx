## ¿Qué hace?

Es una **chuleta buscable de todos los códigos de estado HTTP** con una explicación breve y práctica de qué significa cada uno y **cuándo debería devolverlo tu API**. Busca por número (`404`), por nombre (`unauthorized`) o por palabra clave, y filtra por clase.

## Las cinco clases

| Clase | Significado | Ejemplos |
| --- | --- | --- |
| 1xx | Informativo | 101 Switching Protocols |
| 2xx | Éxito | 200 OK, 201 Created, 204 No Content |
| 3xx | Redirección | 301, 304 Not Modified, 308 |
| 4xx | Error del cliente | 400, 401, 403, 404, 429 |
| 5xx | Error del servidor | 500, 502, 503, 504 |

## Códigos que toda API debería usar bien

- **201** con una cabecera `Location` tras crear un recurso.
- **204** tras un borrado sin nada que devolver.
- **409** para conflictos como duplicados.
- **429** con `Retry-After` al limitar peticiones.
- **503** con `Retry-After` durante un mantenimiento.
