## What does it do?

It is a **searchable cheat sheet of every HTTP status code** with a short, practical explanation of what it means and **when your API should return it**. Search by number (`404`), by name (`unauthorized`) or by keyword, and filter by class.

## The five classes

| Class | Meaning | Examples |
| --- | --- | --- |
| 1xx | Informational | 101 Switching Protocols |
| 2xx | Success | 200 OK, 201 Created, 204 No Content |
| 3xx | Redirection | 301, 304 Not Modified, 308 |
| 4xx | Client error | 400, 401, 403, 404, 429 |
| 5xx | Server error | 500, 502, 503, 504 |

## Codes every API should use well

- **201** with a `Location` header after creating a resource.
- **204** after a delete with nothing to return.
- **409** for conflicts such as duplicates.
- **429** with `Retry-After` when rate limiting.
- **503** with `Retry-After` during maintenance.
