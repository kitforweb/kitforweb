## ¿Qué hace?

**Convierte XML a JSON** y **JSON a XML** conservando la información que los conversores simples pierden: atributos, texto mezclado con elementos hijos, secciones CDATA y comentarios. Opcionalmente, valores como `42` o `true` se tipan como números y booleanos.

Está pensado para **servicios SOAP, integraciones B2B, feeds RSS y APIs antiguas**, donde recibes XML pero tu código habla JSON.

## Ejemplo

```xml
<invoice number="INV-2026-042">
  <total currency="EUR">1250.50</total>
</invoice>
```

queda así

```json
{
  "invoice": {
    "@_number": "INV-2026-042",
    "total": { "@_currency": "EUR", "#text": 1250.5 }
  }
}
```
