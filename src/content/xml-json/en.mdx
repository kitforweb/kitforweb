## What does it do?

It **converts XML to JSON** and **JSON to XML** while keeping the information that simple converters lose: attributes, text mixed with child elements, CDATA sections and comments. Optionally, values like `42` or `true` are typed as numbers and booleans.

It is meant for **SOAP services, B2B integrations, RSS feeds and legacy APIs**, where you receive XML but your code speaks JSON.

## Example

```xml
<invoice number="INV-2026-042">
  <total currency="EUR">1250.50</total>
</invoice>
```

becomes

```json
{
  "invoice": {
    "@_number": "INV-2026-042",
    "total": { "@_currency": "EUR", "#text": 1250.5 }
  }
}
```
