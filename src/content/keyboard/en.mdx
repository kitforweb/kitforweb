## What does it do?

Press any key or combination inside the box and it shows the properties of the **keydown event**: `event.key`, `event.code`, the deprecated `keyCode`, the **location** (left or right Shift, numeric keypad) and the state of the **modifier keys**.

It also writes a **ready-to-paste listener** for that shortcut, comparing `key` case-insensitively so it works with Shift and with any layout.

## Example

Pressing Ctrl+Shift+K gives:

| Property | Value |
| --- | --- |
| event.key | "K" |
| event.code | "KeyK" |
| event.keyCode | 75 |
| ctrlKey, shiftKey | true |
