## ¿Qué hace?

Pulsa cualquier tecla o combinación dentro del recuadro y muestra las propiedades del **evento keydown**: `event.key`, `event.code`, el obsoleto `keyCode`, la **posición** (Shift izquierdo o derecho, teclado numérico) y el estado de las **teclas modificadoras**.

También escribe un **listener listo para pegar** para ese atajo, que compara `key` sin distinguir mayúsculas para que funcione con Shift y con cualquier distribución.

## Ejemplo

Al pulsar Ctrl+Shift+K se obtiene:

| Propiedad | Valor |
| --- | --- |
| event.key | "K" |
| event.code | "KeyK" |
| event.keyCode | 75 |
| ctrlKey, shiftKey | true |
