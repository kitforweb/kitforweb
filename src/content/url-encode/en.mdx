## What does it do?

It **percent-encodes** text so it can travel safely inside a URL, and **decodes** it back. When encoding, it shows the three variants side by side so you can pick the right one:

| Function | Keeps | Typical use |
| --- | --- | --- |
| `encodeURIComponent` | letters, digits and `- _ . ! ~ * ' ( )` | a query value or path segment |
| `encodeURI` | also `: / ? # & = ,` | a complete URL |
| form encoding | like the first one, space becomes `+` | HTML forms, URLSearchParams |

## Example

Building `?q=` with the user input `rock & roll` using `encodeURI` gives `?q=rock%20&%20roll`: the `&` starts a new parameter and the search breaks. With `encodeURIComponent` you get `rock%20%26%20roll`, which arrives intact.

## How to use it

1. Type the text to encode, or switch to **Decode** and paste the encoded text.
2. When decoding form data, enable **+ is a space**.
3. Press **Swap** to round-trip the result.
