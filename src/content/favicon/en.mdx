## What does it do?

From **one image** it generates the **complete set of icons** a modern website needs, plus the files that reference them:

| File | Size | Used by |
| --- | --- | --- |
| favicon.ico | 16, 32, 48 | Browsers, legacy tools |
| favicon.svg | vector | Modern browsers (if the source is SVG) |
| apple-touch-icon.png | 180 | iOS home screen |
| icon-192.png, icon-512.png | 192, 512 | Android, PWA install |
| icon-maskable-512.png | 512 | Android adaptive icons |
| site.webmanifest | — | PWA metadata |

It also writes the **link tags** for your head, and lets you download everything as a **ZIP**.

## Tips

- Start from an **SVG** or a square PNG of at least 512px.
- Logos with thin details become unreadable at 16px: simplify the 16 and 32px versions if needed.
