## What does it do?

It converts any **CSS color** between **HEX, RGB, HSL, OKLCH** and its **CSS name**, and shows the closest named color when there is no exact one. Use the picker or paste any value: `#3b82f6`, `rgb(59 130 246)`, `hsl(217 91% 60%)`, `oklch(62% 0.19 260)` or `cornflowerblue`.

## Example

| Format | Value |
| --- | --- |
| HEX | #3b82f6 |
| RGB | rgb(59 130 246) |
| HSL | hsl(217.2 91.2% 59.8%) |
| OKLCH | oklch(62.31% 0.188 259.81) |
