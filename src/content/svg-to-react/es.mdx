## ¿Qué hace?

Convierte un **SVG en un componente de React**, en **TypeScript (TSX)** o **JavaScript (JSX)**:

- Atributos renombrados para React: `stroke-width` → `strokeWidth`, `class` → `className`, cadenas `style` → objetos.
- Una prop **size** que fija el ancho y el alto (24 por defecto).
- Colores de relleno y trazo sustituidos por **currentColor**, para que el icono siga el color del texto.
- `{...props}` en la raíz para poder pasar `className`, `aria-label` o manejadores de eventos.
- Se quitan los comentarios, el prólogo XML y `xmlns:xlink`; opcionalmente se envuelve en `memo`.

## Uso

Renderízalo como `BellIcon` con `size={20}` y `className="text-indigo-600"`: el icono mide 20px y es índigo.
