## What does it do?

It converts an **SVG into a React component**, in **TypeScript (TSX)** or **JavaScript (JSX)**:

- Attributes renamed for React: `stroke-width` → `strokeWidth`, `class` → `className`, `style` strings → objects.
- A **size** prop that sets width and height (24 by default).
- Fill and stroke colors replaced by **currentColor**, so the icon follows the text color.
- `{...props}` on the root so you can pass `className`, `aria-label` or event handlers.
- Comments, the XML prolog and `xmlns:xlink` removed; optionally wrapped in `memo`.

## Usage

Render it as `BellIcon` with `size={20}` and `className="text-indigo-600"`: the icon is 20px and indigo.
