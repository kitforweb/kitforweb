## ¿Qué hace?

**Convierte caracteres especiales en entidades HTML** para que se muestren como texto en lugar de interpretarse como etiquetas, y **decodifica** las entidades a caracteres.

| Carácter | Con nombre | Decimal | Hexadecimal |
| --- | --- | --- | --- |
| `&` | `&amp;` | `&#38;` | `&#x26;` |
| `<` | `&lt;` | `&#60;` | `&#x3C;` |
| `"` | `&quot;` | `&#34;` | `&#x22;` |
| `é` | `&eacute;` | `&#233;` | `&#xE9;` |

## Cómo se usa

1. Pega texto o HTML para codificarlo. Elige referencias con nombre, decimales o hexadecimales.
2. Activa **Codificar todo lo no ASCII** para convertir también tildes y emojis.
3. Pulsa **Intercambiar** para decodificar entidades encontradas en una página, una base de datos o una respuesta de API.

El decodificador entiende la lista completa de referencias con nombre de HTML5, como `&nbsp;`, `&mdash;` o `&hellip;`.
