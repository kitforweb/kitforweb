## ¿Qué hace?

A partir de **un registro de ejemplo** genera **N registros falsos pero realistas** con exactamente la misma estructura: mismas claves, mismo anidamiento, mismos tipos. Perfecto para poblar una base de datos, montar la interfaz antes de que exista la API o escribir tests.

## Cómo se usa

1. Pega un objeto de ejemplo (o un array; todas sus claves se combinan en una plantilla).
2. Elige cuántos **registros** necesitas (hasta 1.000).
3. Mantén la **semilla** para obtener los mismos datos otra vez, o pulsa **Regenerar**.
4. Copia el array o llévalo a la entrada con Intercambiar para afinarlo.

## Campos reconocidos

| Nombre del campo o valor | Valor generado |
| --- | --- |
| `id` | 1, 2, 3… |
| `email`, `mail` | email realista |
| `firstName`, `lastName`, `name` | nombres de persona |
| `createdAt`, fechas ISO | fecha aleatoria de los últimos 3 años |
| `price`, `amount`, `total` | precio con los mismos decimales |
| `city`, `country`, `zip`, `address` | datos de ubicación |
| `avatar`, `image`, URLs | URL de imagen o web |
| booleanos, otros números y textos | valor aleatorio del mismo tipo |

Los arrays tienen hasta cinco elementos creados a partir del primero, y `null` sigue siendo `null`.
