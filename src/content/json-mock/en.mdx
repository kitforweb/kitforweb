## What does it do?

From **one example record** it generates **N fake but realistic records** with exactly the same structure: same keys, same nesting, same types. Perfect for seeding a database, building a UI before the API exists or writing tests.

## How to use it

1. Paste an example object (or an array; all its keys are merged into one template).
2. Choose how many **records** you need (up to 1,000).
3. Keep the **seed** to get the same data again, or press **Regenerate**.
4. Copy the array or swap it into the input to refine it.

## Recognised fields

| Field name or value | Generated value |
| --- | --- |
| `id` | 1, 2, 3… |
| `email`, `mail` | realistic email address |
| `firstName`, `lastName`, `name` | person names |
| `createdAt`, ISO dates | random date in the last 3 years |
| `price`, `amount`, `total` | price with the same decimals |
| `city`, `country`, `zip`, `address` | location data |
| `avatar`, `image`, URLs | image or website URLs |
| booleans, other numbers and strings | random value of the same type |

Arrays keep up to five items built from their first element, and `null` stays `null`.
