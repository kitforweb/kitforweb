## What does it do?

It lets you **design CSS box-shadows visually**: add as many layers as you need, adjust offset, blur, spread and color of each one, make them **inset**, and see the result on a box and background of your choice.

Start from **Tailwind's presets** (sm to 2xl), or paste an existing `box-shadow` to edit it. Copy the CSS declaration or the Tailwind arbitrary class.

## Anatomy of a layer

`box-shadow: inset? x y blur spread color;`

For example `0 4px 12px -2px rgb(0 0 0 / 0.15)`: 4px down, 12px of blur, slightly smaller than the box, 15% black.
