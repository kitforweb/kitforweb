## ¿Qué hace?

Te permite **diseñar sombras box-shadow de CSS de forma visual**: añade todas las capas que necesites, ajusta el desplazamiento, el desenfoque, la expansión y el color de cada una, hazlas **inset** y mira el resultado sobre la caja y el fondo que elijas.

Parte de los **presets de Tailwind** (de sm a 2xl), o pega un `box-shadow` existente para editarlo. Copia la declaración CSS o la clase arbitraria de Tailwind.

## Anatomía de una capa

`box-shadow: inset? x y desenfoque expansión color;`

Por ejemplo `0 4px 12px -2px rgb(0 0 0 / 0.15)`: 4px hacia abajo, 12px de desenfoque, algo más pequeña que la caja, negro al 15%.
