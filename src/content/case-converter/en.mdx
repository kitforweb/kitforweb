## What does it do?

It converts identifiers and text between the **naming conventions** used in code: `camelCase`, `PascalCase`, `snake_case`, `kebab-case`, `CONSTANT_CASE`, `Title Case`, `Sentence case`, `dot.case`, `path/case` and `Train-Case`. Words are detected from any style, so you can paste a mix.

## Typical uses

- Map database columns (`created_at`) to TypeScript properties (`createdAt`).
- Turn a component name into a file name (`UserProfileCard` → `user-profile-card`).
- Build environment variable names (`apiBaseUrl` → `API_BASE_URL`).

## Example

| user first name | userFirstName | user_first_name | user-first-name |
| XMLHttpRequest | xmlHttpRequest | xml_http_request | xml-http-request |
