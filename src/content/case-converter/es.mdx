## ¿Qué hace?

Convierte identificadores y texto entre las **convenciones de nombres** del código: `camelCase`, `PascalCase`, `snake_case`, `kebab-case`, `CONSTANT_CASE`, `Title Case`, `Sentence case`, `dot.case`, `path/case` y `Train-Case`. Las palabras se detectan desde cualquier estilo, así que puedes pegar una mezcla.

## Usos típicos

- Pasar columnas de base de datos (`created_at`) a propiedades de TypeScript (`createdAt`).
- Convertir el nombre de un componente en nombre de fichero (`UserProfileCard` → `user-profile-card`).
- Crear nombres de variables de entorno (`apiBaseUrl` → `API_BASE_URL`).

## Ejemplo

| Entrada | camelCase | snake_case | kebab-case |
| --- | --- | --- | --- |
| user first name | userFirstName | user_first_name | user-first-name |
| XMLHttpRequest | xmlHttpRequest | xml_http_request | xml-http-request |
