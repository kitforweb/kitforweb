## What does it do?

It reads your **CREATE TABLE** statements and draws the **entity-relationship diagram**: each table with its columns and types, primary keys (PK) and foreign keys (FK) marked, and lines between tables for every relation. Useful to understand an inherited database, document a schema or review a migration.

## How to use it

1. Paste a schema dump (`pg_dump --schema-only`, `mysqldump --no-data`) or your migrations.
2. The diagram updates as you type.
3. Export it as **SVG** or **PNG**, copy the **Mermaid** source, or open it in the Mermaid editor.

## Example

```sql
CREATE TABLE authors (
  id SERIAL PRIMARY KEY,
  name TEXT NOT NULL
);

CREATE TABLE books (
  id SERIAL PRIMARY KEY,
  author_id INT NOT NULL REFERENCES authors(id),
  title TEXT NOT NULL
);
```

draws two tables joined by a one-to-many relation: an author has many books.
