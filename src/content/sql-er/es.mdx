## ¿Qué hace?

Lee tus sentencias **CREATE TABLE** y dibuja el **diagrama entidad-relación**: cada tabla con sus columnas y tipos, las claves primarias (PK) y foráneas (FK) marcadas, y líneas entre tablas por cada relación. Sirve para entender una base de datos heredada, documentar un esquema o revisar una migración.

## Cómo se usa

1. Pega un volcado del esquema (`pg_dump --schema-only`, `mysqldump --no-data`) o tus migraciones.
2. El diagrama se actualiza mientras escribes.
3. Expórtalo como **SVG** o **PNG**, copia el código **Mermaid** o ábrelo en el editor de Mermaid.

## Ejemplo

```sql
CREATE TABLE authors (
  id SERIAL PRIMARY KEY,
  name TEXT NOT NULL
);

CREATE TABLE books (
  id SERIAL PRIMARY KEY,
  author_id INT NOT NULL REFERENCES authors(id),
  title TEXT NOT NULL
);
```

dibuja dos tablas unidas por una relación uno a muchos: un autor tiene muchos libros.
