## ¿Qué hace?

Convierte un **comando cURL** en código listo para usar con **fetch**, **axios** o **HttpClient de Angular**: método, URL, cabeceras, cuerpos JSON o de formulario, subida de archivos y autenticación básica.

Es la forma más rápida de reproducir en tu frontend una petición que viste en las DevTools, en Postman o en la documentación de una API.

## Opciones admitidas

| Opción | Significado |
| --- | --- |
| `-X`, `--request` | método HTTP |
| `-H`, `--header` | cabecera |
| `-d`, `--data`, `--data-raw`, `--data-binary` | cuerpo de la petición |
| `--json` | cuerpo JSON con su Content-Type y Accept |
| `-F`, `--form` | campo o archivo de un formulario multipart |
| `-u`, `--user` | autenticación básica |
| `-b`, `--cookie` | cookies |
| `-G` | enviar los datos como query string |

## Ejemplo de resultado

```js
const response = await fetch("https://api.example.com/v1/orders", {
  method: "POST",
  headers: { "content-type": "application/json" },
  body: JSON.stringify({ "productId": 42 }),
});
const data = await response.json();
```
