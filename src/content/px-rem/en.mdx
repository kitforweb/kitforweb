## What does it do?

It converts CSS lengths between **px, rem and em** using the **root font size** you set (16px by default). Type a single value to see it in every unit, or paste a **whole CSS block** and convert every value at once, leaving `url()` contents and, optionally, 1px borders untouched.

## Formula

`rem = px ÷ root font size`, so with a 16px root: 24px = 1.5rem and 0.875rem = 14px.

## Example

`padding: 24px 32px; margin-bottom: 48px;` becomes `padding: 1.5rem 2rem; margin-bottom: 3rem;`.
