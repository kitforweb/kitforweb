## What does it do?

It **validates a JSON document against a JSON Schema** and tells you exactly **which field fails and why**: every error appears with its path (for example `/user/email`), the rule that failed and a readable message, and the value is underlined in the data editor.

It also works the other way: **generate a schema from an example JSON**, a fast way to start documenting an API payload or a config file.

## How to use it

1. Paste the schema on top and the data below.
2. The result updates as you type.
3. Click an error to see it in the data.

## Example

With a schema that requires `email` with `format: email` and a `plan` that is one of `free` or `pro`, the data `{"email": "ana@", "plan": "gold"}` gives two errors: the email does not match the format and the plan is not one of the allowed values.
