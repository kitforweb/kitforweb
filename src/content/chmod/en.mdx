## What does it do?

It translates Unix permissions between the three ways you meet them: **checkboxes** (read, write and execute for owner, group and others), the **octal mode** that `chmod` takes (`755`) and the **symbolic string** that `ls -l` prints (`rwxr-xr-x`). Change any of them and the others follow.

You can also paste a whole command (`chmod -R 750 /srv/app`), an `ls -l` line (`-rw-r--r--`) or apply a symbolic expression like `u+x,go-w` to see the resulting mode.

## Common modes

| Mode | Symbolic | Typical use |
| --- | --- | --- |
| 644 | rw-r--r-- | Regular files |
| 755 | rwxr-xr-x | Scripts and directories |
| 600 | rw------- | SSH keys, .env files |
| 700 | rwx------ | ~/.ssh |
| 1777 | rwxrwxrwt | /tmp |

Avoid `777`: any user or compromised process on the machine could modify the file.
