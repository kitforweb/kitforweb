## ¿Qué hace?

Convierte un **array de objetos JSON a CSV** —listo para abrir en Excel, Google Sheets o Numbers— y **CSV de vuelta a JSON**. Admite filas con claves distintas: las columnas son la unión de todas las claves encontradas.

## Cómo se usa

1. Pega un array JSON a la izquierda para obtener el CSV a la derecha.
2. Elige el **separador**: coma, punto y coma, tabulador o barra vertical.
3. Pulsa **Intercambiar** para convertir CSV a JSON. En este sentido, **Automático** detecta el separador por ti.

## Ejemplo

```json
[{ "id": 1, "address": { "city": "Madrid" }, "tags": ["a", "b"] }]
```

```csv
id,address.city,tags.0,tags.1
1,Madrid,a,b
```

Los valores que contienen el separador, comillas o saltos de línea se entrecomillan automáticamente, siguiendo el RFC 4180.
