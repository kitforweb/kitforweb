## What does it do?

It is a visual **editor for CSS easing curves**. Drag the two control points of `cubic-bezier()` or type their values, start from presets (the CSS keywords, the easings.net curves and Material's), and press **Play** to compare the motion with a linear animation.

Copy the result for `transition-timing-function` or `animation-timing-function`. When the curve matches a CSS keyword, the keyword is used: `cubic-bezier(0.25, 0.1, 0.25, 1)` is simply `ease`.

## Example

`cubic-bezier(0.34, 1.56, 0.64, 1)` (easeOutBack) overshoots the target a little and settles, a playful effect for menus and toasts.
