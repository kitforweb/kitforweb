## What does it do?

It is a **live editor for HTML, CSS and JavaScript**: write in the three tabs and the preview updates as you type, or turn off auto-run and press **Run**. A built-in **console** shows `console.log`, warnings, errors and unhandled promise rejections with readable objects.

## Libraries

- **Popular libraries** in one click: Tailwind, Pico, Bootstrap, jQuery, Lodash, Alpine.js, Chart.js, GSAP and more.
- Any **script or stylesheet URL** from jsDelivr, unpkg, cdnjs or esm.sh.
- **Import maps**: add `react`, `vue` or any npm package and write `import` statements as in a real project.

## Good for

- Reproducing a bug in isolation before filing an issue.
- Trying a CSS layout or an animation quickly.
- Sharing a small example with a colleague by link.
