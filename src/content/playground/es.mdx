## ¿Qué hace?

Es un **editor en vivo de HTML, CSS y JavaScript**: escribe en las tres pestañas y la vista previa se actualiza mientras escribes, o desactiva la ejecución automática y pulsa **Ejecutar**. Una **consola** integrada muestra `console.log`, avisos, errores y promesas rechazadas sin capturar, con los objetos legibles.

## Librerías

- **Librerías populares** con un clic: Tailwind, Pico, Bootstrap, jQuery, Lodash, Alpine.js, Chart.js, GSAP y más.
- Cualquier **URL de script u hoja de estilos** de jsDelivr, unpkg, cdnjs o esm.sh.
- **Import maps**: añade `react`, `vue` o cualquier paquete de npm y escribe `import` como en un proyecto real.

## Útil para

- Reproducir un bug de forma aislada antes de abrir una incidencia.
- Probar rápido un layout CSS o una animación.
- Compartir un ejemplo pequeño con un compañero por enlace.
