## What does it do?

It runs a regular expression against a **list of test cases** and shows, for each one, whether it **matches** (green) or **not** (red), with the matched part highlighted and every **capture group**, numbered or named, listed underneath. Below, the regex is **explained part by part** in plain language.

## How to use it

1. Type the pattern without slashes, or paste a literal like `/^\d+$/i`: the flags are picked up automatically.
2. Add the **flags** you need: `g` global, `i` ignore case, `m` multiline, `s` dot matches newlines, `u` Unicode.
3. Write one test case per line, mixing strings that should and should not match.
4. Press **Share** to send the pattern and the test cases in a link.

## Common flags

| Flag | Effect |
| --- | --- |
| `g` | find every match, not only the first |
| `i` | ignore upper and lower case |
| `m` | `^` and `$` match at every line |
| `s` | `.` also matches line breaks |
| `u` | full Unicode: emoji and `\p{…}` classes |
