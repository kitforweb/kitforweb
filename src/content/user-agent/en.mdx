## What does it do?

It breaks a **User-Agent** string into its parts:

- **Browser** and version (Chrome, Safari, Firefox, Edge, Samsung Internet…).
- **Rendering engine** (Blink, WebKit, Gecko).
- **Operating system** and version.
- **Device type**: desktop, mobile, tablet, smart TV, console…
- **Bots and tools**: Googlebot, Bingbot, GPTBot, ClaudeBot, social network crawlers, curl, Postman…

When you open the page it shows your own browser's User-Agent, handy for bug reports.

## Where to find it

- In JavaScript: `navigator.userAgent`.
- In server logs, the `User-Agent` request header.
- In Node.js/Express: `req.get("user-agent")`.
