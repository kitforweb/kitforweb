## What does it do?

It turns a **JSON sample** into a **[Zod](https://zod.dev) schema** that validates data with the same shape, plus the TypeScript type inferred from it. Optional fields, nulls and unions are detected from your sample.

## How to use it

1. Paste a JSON object or an array of objects (several examples give better results).
2. Name the schema: `Task` produces `TaskSchema` and `type Task`.
3. Copy the code and refine it with Zod's validators.

## Example

```ts
import * as z from "zod";

export const TaskSchema = z.object({
  "title": z.string(),
  "done": z.boolean(),
  "dueDate": z.null(),
});
export type Task = z.infer<typeof TaskSchema>;

const task = TaskSchema.parse(await res.json()); // throws if the API changed
```

## When the root is an array

If your sample is an array, the tool generates the schema for one element and an extra `z.array(...)` schema for the whole list.
